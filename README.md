# cnation STS — 첨탑을 오르다

> **Version 1.0.10**

원작 **Slay the Spire (1편)** 의 규칙을 그대로 재현한 **모바일 세로형 웹 게임**입니다.
스마트폰 브라우저에서 바로 실행되며, 컴퓨터(AI)가 조종하는 몬스터와 1층부터 50층까지 대결합니다.

* 카드/UI : **HTML + CSS + 인라인 SVG** (외부 이미지 파일 0개, 모든 문양은 벡터로 생성)
* 캐릭터/몬스터 : **three.js 절차적 저폴리 모델** (외부 3D 모델·텍스처 0개)
* 효과음 : **WebAudio 합성** (외부 음원 파일 0개)
* 빌드 도구 불필요 — 순수 ES 모듈, 정적 호스팅만으로 동작

## 1. 실행 방법

### 로컬
```bash
# 정적 서버라면 무엇이든 가능합니다
npx serve .            # 또는  npm run dev
python3 -m http.server 8080
```
→ 브라우저에서 `http://localhost:8080` 접속 (모바일 뷰로 보면 가장 자연스럽습니다).

> `file://` 로 직접 열면 ES 모듈 CORS 정책 때문에 동작하지 않습니다. 반드시 서버로 여세요.

### Vercel 배포
정적 사이트라 별도 설정이 필요 없습니다.

```bash
vercel            # 프리뷰
vercel --prod     # 프로덕션
```
* Framework Preset : **Other**
* Build Command : 비움
* Output Directory : `.`

`vercel.json` 에 캐시/보안 헤더가 이미 들어 있습니다.
배포 후 모바일에서 **홈 화면에 추가** 하면 전체화면 앱처럼 실행됩니다 (`manifest.webmanifest` 포함).

## 2. 조작 방법 (세로형 원터치)

| 동작 | 조작 |
|---|---|
| 캐릭터 선택 | 새 게임 → 4명 중 선택 → **시작 보너스** 선택 |
| 카드 선택 | 카드를 **탭** (선택된 카드는 가운데에서 크게 표시) |
| 카드 사용 | 선택된 카드를 **한 번 더 탭** 하거나 **위로 밀기(스와이프)** |
| 대상 지정 | 적이 둘 이상이면 빨간 화살표가 뜬 **적을 탭** |
| 턴 종료 | 우측 하단 **턴 종료** |
| 더미 확인 | 좌/우 하단 **뽑을 · 버린 · 소각** 버튼 |
| 물약 사용 | 하단 물약 슬롯 탭 |
| 상태이상 설명 | 적/플레이어의 아이콘 탭 |
| 유물 설명 | 상단 유물 아이콘 탭 |

진행 상황은 매 층마다 `localStorage` 에 자동 저장되며 타이틀의 **이어하기** 로 복귀합니다.

## 3. 재현한 원작 규칙

### 층 구조 (요청 사양 그대로)
| 막 | 층 | 보스 |
|---|---|---|
| 1막 | 1 ~ 17층 | **17층 중간 보스** |
| 2막 | 18 ~ 34층 | **34층 중간 보스** |
| 3막 | 35 ~ 50층 | **50층 최종 보스** |

* 중간 보스(17층·34층)를 처치하면 **다음 막을 체력 최대치로 시작**합니다.
* 지도는 원작처럼 분기형이며, 각 막 중간에 보물 방, 보스 직전 행에 모닥불이 고정 배치됩니다.
* 방 종류 : 전투 / 정예 / ? 의문(이벤트) / 모닥불 / 상점 / 보물 / 보스

### 전투 규칙
* 매 턴 에너지 3, 카드 5장 드로우. 손패 최대 10장.
* 방어도는 턴 종료 시 사라짐 (바리케이드·캘리퍼스 예외).
* 피해 계산 순서 : `기본값 + 힘(+활력) → 약화 ×0.75 → 취약 ×1.5 → 내림` 후 방어도 차감.
* **취약** 받는 공격 피해 +50% / **약화** 주는 피해 −25% / **허약** 얻는 방어도 −25%
* **중독**은 해당 액터의 턴 시작에 피해 후 1 감소, **금속화·도금 갑옷·연소·재생**은 턴 종료에 발동.
* **인공물**이 디버프를 1개씩 무효화, **무형**은 받는 피해를 1로, **완충**은 체력 손실 1회 무효.
* 지속시간형 디버프(취약/약화/허약/무형)는 **소유자 턴 종료 시** 1 감소.
* 소각 / 소멸 / 내재 / 보존 / X 비용 / 혼란(무작위 비용) 모두 구현.
* 적의 **의도(Intent)** 를 아이콘 + 예상 피해량(힘·약화·취약 반영)으로 표시. 룬 돔은 의도를 가립니다.
* 분열(슬라임), 형태 변환(수호자), 각성(깨어난 자), 시간 왜곡(시간 포식자), 수하 소환 등 보스 고유 기믹 포함.

### 보상 규칙
* 일반 10~20G / 정예 25~35G / 보스 95~105G
* 카드 보상 3장 (물음표 카드 +1, 부서진 왕관 −2, 기도 바퀴 일반전투 +1)
* 희귀도 롤 : 일반 → 고급 → 희귀, **희귀가 나오면 다음 확률 보정**(원작의 rarity bonus 방식)
* 2막 12.5% / 3막 25% 확률로 보상 카드가 강화 상태로 등장
* 물약 드랍 확률 40% 에서 획득 시 −10%p, 실패 시 +10%p
* 정예 처치 시 유물, 보스 처치 시 **보스 유물 3종 중 택 1**

## 8. 변경 이력

### v1.0.10
- **범례 아이콘 20% 확대** (20px → 24px, 썸네일 굽는 해상도도 48 → 64px)
- **"정예" → "엘리트"** : 원작 명칭에 맞춰 지도 범례·방 이름·유물/이벤트 설명·결과 화면 전부 변경
- **의문 방 아이콘을 실제 물음표로 재설계** : 오른쪽 아래가 열린 고리 + 꼬리 + 점,
  회전시키지 않고 항상 정면을 유지해 어느 각도에서도 `?` 로 읽힘
- **상점 아이콘을 노점 형태로 재설계** : 빨강/흰 줄무늬 차양, 판매대와 카운터, 금빛 앞단 테두리,
  진열된 물약병과 금화 더미
- **지도 배경 그라디언트** : 새카만 바탕 대신 위쪽 보랏빛 · 아래쪽 주황빛이 은은하게 도는
  다층 그라디언트 + 가장자리 비네팅

### v1.0.9
- **막별 배경 색 계통 분리** : 1막(1~17층) 어두운 회색 석조 · 2막(18~34층) 어두운 갈색 목조 ·
  3막(35~50층) 어두운 보라 심층. 안개·바닥·기둥·아치 색과 조명(주광/역광/환경광/불빛) 색조까지 함께 바뀜
- **층별 절차적 변주** : 기둥 수(7~11)·높이·굵기·면수, 아치 개수(2~4)·크기·간격, 바닥 무늬 링(1~3),
  색조 지터가 층마다 달라져 같은 막 안에서도 배경이 조금씩 다름
- **층별 소품 2종 무작위 배치** : 돌무더기 / 늘어진 사슬 / 횃불 / 떠 있는 수정 / 뒤쪽 계단
  (횃불은 일렁이고 수정은 위아래로 부유)
- 층 번호로 고정된 난수를 쓰므로 **같은 층은 다시 들어가도 같은 배경**

### v1.0.8

### v1.0.6
- **모달 상단 상태 띠** : 보상·보물상자·모닥불·상점·이벤트·네오우 등 선택 화면 어디서나
  **현재 체력 / 보유 골드 / 물약 슬롯**을 위쪽에 고정 표시
  - 물약 슬롯은 채워진 칸(물약 색)과 빈 칸(점선)을 그대로 보여 주고 **"빈칸 N"** 또는 **"가득참"** 표기

  - 보상을 받을 때마다 즉시 갱신되므로 남은 칸·골드를 보고 이어서 판단 가능
- **모닥불 휴식 미리보기** : "체력을 24 회복합니다. (47 → 71 / 80)" 처럼 회복 후 체력을 함께 표시

- **번개 구체 개별 발사** : 번개 구체가 2개 이상일 때 구체 수만큼 각각의 위치에서
  시차를 두고 따로 발사 (기존에는 한 줄기에 피해만 합산되어 보였음)
- **전투 연출 속도 2배** : 플레이어·몬스터의 공격 모션과 피격·사망 연출, 턴 간 딜레이를 모두 2배로 늘려 눈에 잘 보이도록 조정
- **배경 노이즈 제거** : 게임 내내 깔리던 "우우웅" 앰비언스 사운드 완전 삭제
- **몬스터 본체 탭으로 대상 선택** : 머리 위 이름표가 아니라 몬스터 3D 본체를 직접 눌러 공격 대상 지정 (대상 지정 중에는 붉은 링 표시)
- **내 체력바를 녹색 계열로** 변경 (상단바·유닛 체력바 모두)
- **체력바 길이 차등** : 최대 체력에 따라 막대 길이를 다르게 하되 차이를 1/4 로 압축
  (내 2배 체력 → 길이 +25%, 내 60% 체력 → 길이 −10%)
- **IBM Plex Sans KR 전면 적용** (제목·카드·UI 전체)
- **카드 설명 글씨 15% 확대** — 스마트폰에서의 가독성 개선

### v1.0.2
- **실시간 수치 반영** : 힘·약화·취약·민첩·허약·자세가 적용된 **실제 수치**를 그대로 표시
  - 적 머리 위 의도 : 약화를 걸면 그 즉시 예상 피해가 줄어든 값으로 바뀜
  - 손에 든 카드 : 힘을 얻으면 피해 수치가 즉시 증가하며, **달라진 숫자만 초록(증가)/주황(감소)** 으로 강조
- **지도 가독성** : 현재 위치에 빛기둥·흰 링 표식, 갈 수 있는 길은 금색 화살표 + 굵고 밝은 경로,
  갈 수 없는 길은 흐리게 처리
- **상점** : 카드 제거 시 "이 카드를 제거하시겠습니까?" 확인 단계 추가,
  매 상점마다 무작위 상품 1개가 **반값 또는 80% 할인** (할인 배지 + 원가 취소선)
- **디펙트 구체** : 주인공 주위를 도는 3D 구체로 전면 교체
  - 원작과 동일한 배치 — 먼저 발동할 구체가 **오른쪽(몬스터 쪽)**, 다음이 **머리 위**, 그다음이 **왼쪽**
  - 새 구체는 왼쪽에서 충전되고 기존 구체가 한 칸씩 밀려 이동하는 애니메이션
  - 발동 연출 : 번개는 갈라지는 번개 줄기, 암흑은 투사체, 냉기는 방어막, 플라즈마는 상승 섬광
  - 전용 합성 효과음 4종(천둥·얼음·암흑·플라즈마) + 충전음 추가
- **강화 절차 간소화** : 카드를 고르면 곧바로 강화 전/후 비교 화면으로 (중간 확인 1단계 제거)
- **초반 난이도** : 첫 전투를 기존 2번째 전투 수준(체력 75%·피해 70%)으로, 두 번째 전투부터는 일반 난이도
- 버그 수정 : 턴 시작 피해(유물·중독 등)로 마지막 적이 죽어도 전투가 끝나지 않던 문제
