# cnation STS — 첨탑을 오르다

> **Version 1.3.1**

원작 **Slay the Spire (1편)** 의 규칙을 그대로 재현한 **모바일 세로형 웹 게임**입니다.
스마트폰 브라우저에서 바로 실행되며, 컴퓨터(AI)가 조종하는 몬스터와 1층부터 50층까지 대결합니다.

* 카드/UI : **HTML + CSS + 인라인 SVG** (외부 이미지 파일 0개, 모든 문양은 벡터로 생성)
* 캐릭터/몬스터 : **three.js 절차적 저폴리 모델** (외부 3D 모델·텍스처 0개)
* 효과음 : **WebAudio 합성** (외부 음원 파일 0개)
* 빌드 도구 불필요 — 순수 ES 모듈, 정적 호스팅만으로 동작

## 1. 실행 방법

### 로컬
```bash
# 정적 서버라면 무엇이든 가능합니다
npx serve .            # 또는  npm run dev
python3 -m http.server 8080
```
→ 브라우저에서 `http://localhost:8080` 접속 (모바일 뷰로 보면 가장 자연스럽습니다).

> `file://` 로 직접 열면 ES 모듈 CORS 정책 때문에 동작하지 않습니다. 반드시 서버로 여세요.

### Vercel 배포
정적 사이트라 별도 설정이 필요 없습니다.

```bash
vercel            # 프리뷰
vercel --prod     # 프로덕션
```
* Framework Preset : **Other**
* Build Command : 비움
* Output Directory : `.`

`vercel.json` 에 캐시/보안 헤더가 이미 들어 있습니다.
배포 후 모바일에서 **홈 화면에 추가** 하면 전체화면 앱처럼 실행됩니다 (`manifest.webmanifest` 포함).

## 2. 조작 방법 (세로형 원터치)

| 동작 | 조작 |
|---|---|
| 캐릭터 선택 | 새 게임 → 4명 중 선택 → **시작 보너스** 선택 |
| 카드 선택 | 카드를 **탭** (선택된 카드는 가운데에서 크게 표시) |
| 카드 사용 | 선택된 카드를 **한 번 더 탭** 하거나 **위로 밀기(스와이프)** |

| 턴 종료 | 우측 하단 **턴 종료** |
| 더미 확인 | 좌/우 하단 **뽑을 · 버린 · 소각** 버튼 |
| 물약 사용 | 하단 물약 슬롯 탭 |
| 상태이상 설명 | 적/플레이어의 아이콘 탭 |

## 3. 재현한 원작 규칙

### 층 구조 (요청 사양 그대로)
| 막 | 층 | 보스 |
|---|---|---|
| 1막 | 1 ~ 17층 | **17층 중간 보스** |
| 2막 | 18 ~ 34층 | **34층 중간 보스** |
| 3막 | 35 ~ 50층 | **50층 최종 보스** |

* 중간 보스(17층·34층)를 처치하면 **다음 막을 체력 최대치로 시작**합니다.
* 지도는 원작처럼 분기형이며, 각 막 중간에 보물 방, 보스 직전 행에 모닥불이 고정 배치됩니다.
* 방 종류 : 전투 / 정예 / ? 의문(이벤트) / 모닥불 / 상점 / 보물 / 보스

### 전투 규칙
* 매 턴 에너지 3, 카드 5장 드로우. 손패 최대 10장.
* 방어도는 턴 종료 시 사라짐 (바리케이드·캘리퍼스 예외).
* 피해 계산 순서 : `기본값 + 힘(+활력) → 약화 ×0.75 → 취약 ×1.5 → 내림` 후 방어도 차감.
* **취약** 받는 공격 피해 +50% / **약화** 주는 피해 −25% / **허약** 얻는 방어도 −25%
* **중독**은 해당 액터의 턴 시작에 피해 후 1 감소, **금속화·도금 갑옷·연소·재생**은 턴 종료에 발동.
* **인공물**이 디버프를 1개씩 무효화, **무형**은 받는 피해를 1로, **완충**은 체력 손실 1회 무효.
* 지속시간형 디버프(취약/약화/허약/무형)는 **소유자 턴 종료 시** 1 감소.
* 소각 / 소멸 / 내재 / 보존 / X 비용 / 혼란(무작위 비용) 모두 구현.
* 적의 **의도(Intent)** 를 아이콘 + 예상 피해량(힘·약화·취약 반영)으로 표시. 룬 돔은 의도를 가립니다.
* 분열(슬라임), 형태 변환(수호자), 각성(깨어난 자), 시간 왜곡(시간 포식자), 수하 소환 등 보스 고유 기믹 포함.

### 보상 규칙
* 일반 10~20G / 정예 25~35G / 보스 95~105G
* 카드 보상 3장 (물음표 카드 +1, 부서진 왕관 −2, 기도 바퀴 일반전투 +1)
* 희귀도 롤 : 일반 → 고급 → 희귀, **희귀가 나오면 다음 확률 보정**(원작의 rarity bonus 방식)
* 2막 12.5% / 3막 25% 확률로 보상 카드가 강화 상태로 등장
* 물약 드랍 확률 40% 에서 획득 시 −10%p, 실패 시 +10%p
* 정예 처치 시 유물, 보스 처치 시 **보스 유물 3종 중 택 1**

## 8. 변경 이력

### v1.3.1 — 테스트용 판은 전적에서 제외
- 숨겨진 시작 보너스를 쓴 판은 **게임 테스트용**이므로 전적에 **아예 기록하지 않는다** (`recordRun` 이 `run.cheat` 이면 바로 반환)
- 요약 · 캐릭터별 표 · 막대그래프뿐 아니라 **최근 기록 목록에서도 사라진다**
- 1.3.0 이전에 쌓인 기록에 그런 판이 남아 있을 수 있어 `Records.stats` 가 `recent` 까지 한 번 더 걸러 낸다 (`used` 기준으로 변경)
- 표시할 일이 없어진 ★ 칸과 "숨겨진 보너스를 쓴 N판은 집계에서 제외" 안내 문구, `cheatRuns` 집계값을 제거
- `Records.stats` 의 `includeCheat` 옵션도 함께 제거 — 포함할 경로가 더는 없다

### v1.3.0 — 계정 · 전적
한 기기를 여러 사람이 쓸 수 있도록 **계정** 개념을 넣고, 계정마다 **전적 통계**를 남긴다.

**계정 (`js/profile.js`)**
- 한 기기에 **최대 5개**. 비밀번호 없음, 기기 간 동기화 없음 — 각자 자기 기기에서 쓰는 전제
- 처음 실행하면 이름을 받아 계정을 만들고 바로 시작 (`askFirstProfile`)
- 타이틀 화면의 **이름표(`.profile-chip`)** 를 누르면 계정 목록 — 전환 · 추가 · 전적 보기 · 삭제
- **마지막에 쓴 계정이 다음 실행에도 그대로 선택된다** (`activeId` 저장)
- 삭제는 **확인창 한 번** — 그 계정의 전적과 진행 중인 게임까지 함께 지운다
- 같은 이름은 거절 (`이미 있는 이름입니다.`), 이름은 12자까지

**저장 분리**
- 저장 키가 계정별로 갈라진다 : `cnation_sts_save_<계정id>` · `cnation_sts_runs_<계정id>`
- `run.js` 에 `setSaveKey()` / `getSaveKey()` 추가 — 계정을 바꾸면 이어하기 대상도 함께 바뀐다
- 타이틀의 **이어하기** 버튼은 지금 계정에 진행 중인 런이 있을 때만 활성
- 계정 도입 전 저장(`cnation_sts_save_v1`)이 있으면 **첫 계정으로 1회 이전** (`Profiles.migrateLegacy`)

**전적 (`Records`)**
- 한 판이 끝날 때마다 한 건 기록 — 사망 · 클리어 · 포기 (최대 500건, 오래된 것부터 밀려난다)
- 남기는 값 : 캐릭터 · 결과 · 도달 층 · 막 · 처치 수 · 엘리트/보스 처치 · 덱 장수 · 유물 수 · 소요 시간 · 치트 여부
- **통계는 저장하지 않고 읽을 때 계산한다** — 기록과 통계가 어긋날 일이 없다
- 전적 화면 : 요약 4칸(총 판수 · 클리어 · 평균 도달 층 · 최고 기록) + 캐릭터별 표 + 막별 막대그래프 + 최근 30판
- **포기한 판은 평균·클리어율에서 빼고 따로 센다** (숨겨진 시작 보너스를 쓴 판의 처리는 v1.3.1 참고)

**로컬 우선**
- 전부 `localStorage` — 서버 없이 완전히 동작한다. 클라우드 백업(Firebase 익명 인증)은 이후 버전에서 얹을 자리만 비워 두었다

**버그 수정**
- 지도 화면의 **설정** 버튼이 눌리지 않던 문제 — 타이틀 톱니 버튼과 `id="btn-settings"` 가 겹쳐 있어 이벤트가 전부 타이틀 쪽에 붙고 있었다. 타이틀 쪽을 `btn-settings-title` 로 분리

### v1.2.4 — 변경 이력 강조 표시
- 변경 이력에서 **minor 버전(끝자리 0)** 항목의 제목을 굵고 밝은 흰색으로 강조 (`.rel.big .rel-note`)
- 판정은 `/^\d+\.\d+\.0$/` — 현재 `1.1.0` · `1.2.0` 두 건이 해당

### v1.2.3 — 전체 대상 카드 수정
- **버그 수정** — 모든 적에게 거는 카드인데 대상 선택창이 뜨던 문제
  - 원인 : `Card.target` 게터가 `def.target` 만 보고 있어 **강화로 대상 범위가 바뀌는 카드**를 반영하지 못했다. `exhaust`/`ethereal`/`innate`/`retain` 은 이미 `~U` 접미사로 강화판을 지원하고 있었는데 `target` 만 빠져 있었다
  - 수정 : `def.targetU` 지원 추가 후 `실명(blind)` · `걸어 넘어뜨리기(trip)` 에 `targetU: ALL` 지정
  - **363장 전수 감사** — 텍스트의 "모든 적" 여부와 `play` 안의 `living()` 사용 여부를 대조. 해당 2장 외에 문제 없음을 확인
    - `시체 폭발` · `압점` · `볼링 강타` 는 단일 대상 지정이 맞아 그대로 둠 (전체 효과는 지정한 적을 기점으로 발생)
    - `target: all` 로 이미 올바른 카드 22장, 반대 방향 오류 0건, 물약 0건
  - 카드 상세의 대상 표기(`적 1체 지정` / `적 전체`)도 강화 여부에 따라 바뀐다

### v1.2.2 — 복귀 후 소리 복구 · 기본 음량 50%
- **버그 수정** — 앱을 전환했다 돌아오면 배경음악·효과음이 **둘 다** 무음이 되고, 설정 토글로도 복구되지 않던 문제

## 9. 숨겨진 기능 (치트)

게임 안에서는 어디에도 표시되지 않습니다. 게임 내 변경 이력(`js/data/changelog.js`)
에도 일부러 적지 않았습니다.

**발동 방법** — 새 게임 → `시작 보너스` 화면에서 **네 번째 선택지 아래, 아무것도
그려져 있지 않은 자리**(높이 54px)를 탭합니다. (`.choice-secret`)

**효과** (`NEOW_SECRET` in `js/data/neow.js`)

| 항목 | 내용 |
|---|---|
| 최대 체력 | **2배** (그만큼 회복해서 가득 찬 상태로 시작) |
| 공격 카드 피해 | **2배** — `attackValue()` 에서 `card && run.cheat` 일 때만. 가시·중독 같은 카드 외 피해는 그대로 |
| 방어 카드 방어도 | **2배** — `gainBlock()` 에서 `card && !raw && run.cheat` 일 때만. 유물·힘으로 얻는 방어도는 그대로 |
| 물약 효과 | **2배** — 신성한 나무껍질 유물과 같은 배율 |
| 골드 | 선택 즉시 가진 골드가 **2배**, 이후 얻는 골드도 전부 **2배** — `gainGold()` 한 곳에서 처리하므로 전투 보상·상자·이벤트·유물 전부 적용 |
| 유물 | 일반 유물 1개 + 엘리트 유물 1개(`relicReward()`) |

`run.cheat` 플래그로 관리하며 저장/불러오기에 함께 보존됩니다.
